# Go-to-Market

## Funnel

Use AIAAR to classify each method by the transition it is intended to create:

```text
Unknown → Aware → Interested → Downloaded → Activated → Returned
```

- Awareness: the user learns Limerence exists.
- Interest: the user investigates whether it solves their problem.
- Acquisition: the user downloads and installs it.
- Activation: the user connects real data and experiences meaningful value.
- Retention: the user returns and uses it again.

Downloading is not activation. Activation requires meaningful value from real
data.

## Delivery boundary

No untriggered prospecting. Outbound delivery is acceptable only after an
inbound action, explicit permission, or an existing relationship.

Do not use:

- cold email, calls, or direct messages;
- purchased or scraped prospect lists;
- seller-initiated contact without a prior signal;
- agency-dependent acquisition;
- organic social publishing or founder personal-brand building.

## Core positioning

- Stop being the bottleneck for every data request.
- Ask business questions in plain language and get analyst-quality insights.
- A focused desktop workspace, not another browser dashboard.
- Your LLM keys, your costs, your control.
- Keep agents, conversations, data sources, dashboards, reports, and
  automations in one app.

## Persona messages

- **Operations and data owners:** Let teams self-serve trusted answers while you
  focus on analysis, systems, and strategy.
- **Business users:** Ask company data questions in plain language without
  waiting for a custom query or report.
