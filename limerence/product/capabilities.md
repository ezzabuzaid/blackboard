# Product Capabilities

## Core experience

- Native desktop workspace with a persistent sidebar and local app state
- Conversational exploration with follow-up context
- Analyst-style answers with key takeaways, trends, and anomalies
- Interactive and agentic dashboards, charts, KPI cards, tables, and controls
- Clarification when a request is ambiguous
- Human approval for sensitive tool actions
- Durable streaming, cancellation, resume, history, and sharing

## All Ties Together

Connections are where data lives. Spaces are where work lives. Limerence does the work.

Initially, users have to specify a model provider and provide their own credentials or use their Claude/ChatGPT subscription.

Limerence connects to the provider, and then the user can connect to a data source. Once connected, the user can create an agent that is grounded in the data source and can be used to answer questions about the data.

Spaces are where the user can create and manage agents, conversations, dashboards, reports, and scheduled automations.

## Data and grounding

- PostgreSQL
- MySQL and MariaDB
- Microsoft SQL Server
- SQLite
- BigQuery
- XLSX and CSV spreadsheets
- Schema introspection and relationship discovery
- Table filtering and grounding controls
- Structured domain terminology, business rules, examples, and guardrails
- Read-only connection enforcement and query-safety checks

## Desktop workspace

- Data-source discovery, setup, and connection management
- Agent creation, teaching, grounding, capabilities, shortcuts, and statistics
- Conversation history and durable local workspaces
- Dashboard creation and management
- Structured reports
- Weekly and hourly scheduled agent runs
- Full run history through standard conversations
- AI-provider setup and model selection

Gemini, Groq, MiniMax, OpenRouter, Ollama, LM Studio, and compatible providers.
