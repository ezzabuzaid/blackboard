# Limerence Business Profile

This directory is the shared business context for Limerence. Read the files
relevant to the current request before making business, product, operational,
or strategy recommendations.

## Map

- `company/overview.md` — company, problem, solution, model, and differentiators
- `product/capabilities.md` — current desktop product surface
- `market/icp.md` — ideal customer, users, pains, objections, and anti-ICP
- `commercial/go-to-market.md` — acquisition boundaries and positioning
- `strategy/vision.md` — current stage, direction, and explicit exclusions
- `brand/messaging.md` — approved headline messages and visual identity

## Accuracy rules

- Distinguish shipped capabilities from future direction.
- Limerence is a desktop application. Keep descriptions centered on the local
  desktop experience.
- Limerence is pre-launch beta with no paying customers yet. Do not invent
  traction, customers, case studies, or revenue.
